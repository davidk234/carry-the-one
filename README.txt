CARRY THE ONE  (offline version)

On a computer, with no setup:
  Double-click index.html. It opens in your browser and works with no internet.

On a phone (one-time setup, then it works offline):
  1. Put this folder on a free host like GitHub Pages (steps in the chat).
  2. Open that link on your phone once while online.
  3. iPhone: Safari > Share > Add to Home Screen.
     Android: Chrome > menu > Install app (or Add to Home screen).
  4. Open it from the home screen once more. After that it works in airplane mode.

Progress is saved on each device. To move it between devices use
Stats > Settings > Copy save code, then Load save code on the other device.
